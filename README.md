Synthetic Respiratory Datasets: Evaluating Clinical Validity and LLM-Induced Overfitting
This repository contains the synthetic respiratory (Asthma) datasets generated and analyzed in the research paper: "The Illusion of Fidelity: The Dual Trap of Clinical Invalidity and LLM-Induced Overfitting in Synthetic Respiratory Data"

📋 Overview
While Large Language Models (LLMs) can generate synthetic clinical data that strictly adheres to clinical guidelines, they often apply these rules as rigid, deterministic constraints. This removes the natural noise, variance, and clinical uncertainty inherent in real-world patient data, leading to severe overfitting in machine learning models (artificially high accuracy ~100%).

This repository provides two synthetic asthma datasets generated by two different LLM paradigms to demonstrate this phenomenon:

Gemini Dataset: Exhibits hyper-determinism, leading to severe overfitting.
Perplexity Dataset: Balances clinical logic with natural statistical variance, leading to realistic, generalizable model performance.

📊 Dataset Description
Both datasets were generated using precisely engineered prompts containing domain-specific constraints (clinical guidelines, physiological boundaries, and diagnostic hierarchies for Asthma).

1. gemini_asthma_dataset.csv
Generator Model: General-purpose conversational LLM (Gemini).
Characteristics: Clinically valid (no physiological impossibilities or fatal contraindications), but highly deterministic.
Machine Learning Behavior: Models trained on this dataset achieve near-perfect metrics (Accuracy, Precision, Recall, and AUC ≈ 1.00).
Statistical Profile:
PCA Explained Variance (2 Components): 79.5% (Perfectly separable, non-overlapping class clusters).
Feature-Target Correlations: Extreme values approaching +1 or -1.
2. perplexity_asthma_dataset.csv
Generator Model: Search-augmented LLM (Perplexity).
Characteristics: Clinically valid while preserving the natural variance and uncertainty of real-world patient populations.
Machine Learning Behavior: Models trained on this dataset achieve realistic, generalizable metrics (Accuracy: 74% - 89% depending on the algorithm).
Statistical Profile:
PCA Explained Variance (2 Components): 16.9% (Substantial class overlap, mimicking real-world clinical uncertainty).
Feature-Target Correlations: Realistic, weak-to-moderate values.
